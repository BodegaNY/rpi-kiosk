Raspberry Pi 3 B+ — GPIO header map (kiosk arcade button)

Default software uses BCM GPIO 17, which is physical pin 11. Connect the button between that pin and GND. Do not connect the button to 3.3 V or 5 V.

40-pin header J8 — Hold the Pi so the GPIO row is along the right edge of the board (USB ports toward you). Pin 1 is the corner pin nearest the microSD slot (often a square pad on the PCB). Odd pins are on the inside row (toward the board); even pins on the outside row.

Never connect the arcade switch to pin 1 / 17 (3.3 V) or pin 2 / 4 (5 V) for this project — only GPIO + GND.

Default signal pin (gpio_button_bcm=17 → physical 11)
GND — safe ground for the button
Other GPIO (not used unless you change config)
3.3 V — do not use for the switch
5 V — do not use for the switch
  1. Unplug the Pi or turn it off while you change wiring.
  2. One Dupont lead: pin 11 → one tab on the arcade button.
  3. Second lead: GND (e.g. pin 6) → the other tab.
  4. Power on; in software, set gpio_button_bcm to 17 or KIOSK_GPIO_BUTTON_BCM=17.
